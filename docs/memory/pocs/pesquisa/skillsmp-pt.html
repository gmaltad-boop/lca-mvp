Perguntas Frequentes

Um guia prático sobre agent skills: o que são, como inspecionar fontes e como o SkillsMP ajuda a explorar o ecossistema.

O que são Agent Skills?

Agent Skills são instruções reutilizáveis e arquivos de apoio que ensinam um assistente de IA a lidar com um tipo específico de tarefa. Uma skill geralmente começa com um arquivo SKILL.md e pode incluir scripts, templates, exemplos ou notas de domínio. O SkillsMP coleta exemplos públicos para mostrar o que pessoas em diferentes áreas estão transformando em skills.

Como instalo Agent Skills pelo SkillsMP?

Abra a fonte da skill no GitHub e siga as instruções do repositório. Em muitos setups, instalar significa copiar a pasta da skill para o diretório de skills usado pelo seu assistente ou sistema de plugins. Leia sempre SKILL.md e quaisquer scripts antes de adicioná-los ao seu ambiente.

Essas skills são seguras?

O SkillsMP indexa repositórios públicos do GitHub; ele não certifica que toda skill é segura ou de alta qualidade. Trate skills da comunidade como qualquer código open source: inspecione a fonte, revise scripts e permissões, confira atividade recente e instale apenas o que você entende.

Este site é afiliado à Anthropic ou OpenAI?

Não. O SkillsMP é um projeto comunitário independente. Ele agrega fontes públicas do GitHub para facilitar a descoberta de skills, mas documentação oficial e skills oficiais devem ser verificadas nos sites dos respectivos fornecedores.
